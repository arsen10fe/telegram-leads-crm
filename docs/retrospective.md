# Ретроспектива

*Черновик: таймлайн по git-истории и скриншоты добавим после деплоя.*

## Как делали

Работали в Claude Code с набором скиллов AI Factory. Порядок был такой.

1. **Разбор ТЗ и прошлых проектов** (`/aif`). Четыре субагента параллельно изучили наши прошлые
   CRM и Telegram-боты и выписали, что переиспользовать и на чём уже обжигались. Главный вывод:
   проверяющий сам напишет боту, поэтому путь «бот → лид → тег» не должен зависеть от AI.
2. **Решения с вопросами ко мне.** Агент задавал вопросы с вариантами и рекомендацией: какие
   AI-функции делаем, как делать пункт 2 (Telegram Business), стек, хостинг.
3. **Архитектура и свои скиллы** (`/aif-architecture`, `/aif-skill-generator`). Перед кодом агент
   собрал два проектных скилла — по боту и по AI-слою — из официальной документации и наших прошлых
   проектов, с проверкой на prompt injection.
4. **План и второй проход по нему** (`/aif-plan`, `/aif-improve`). Второй проход сверял план с
   исходниками библиотек и нашёл 13 проблем до первой строки кода: например, процесс бота упал бы
   на `server-only`, а за nginx не работала бы ни одна форма.
5. **Реализация** (`/aif-implement`) — 29 задач, каждая с тестами и проверкой в браузере через
   Chrome DevTools MCP. 230+ тестов, включая сквозной тест «анкета → лид → тег» на реальной БД.
6. **Деплой и документы.**

## Какие AI-инструменты и для чего

- **Claude Code (Opus)** — исследование, планирование, код, ревью. Субагенты — для параллельного
  чтения прошлых проектов и независимого ревью кода на баги и безопасность.
- **AI Factory** — каркас процесса: описание проекта, архитектура, план с чекбоксами, правила.
- **Context7 и документация в `node_modules`** — сверка API с актуальными версиями, а не с памятью
  модели. Это окупилось: в Next 16.3 у `error.tsx` параметр `retry`, а не `reset`; адаптер Prisma для
  Postgres сдвигал бы все даты на 3 часа, если база не в UTC (нашли по исходникам, когда упал тест).
- **OpenAI внутри продукта** — квалификация лидов, черновики, автопилот со строгими схемами ответа.

Промпты и решения по шагам — в [process-log.md](process-log.md).
